# Project Title
HR Analytics
# Project Overview
Interactive HR Analytics dashboard built in Power BI, with data cleaning and transformation handled in power query.
The dashboard analyzes workforce composition and demographics to support HR decison-making around headcount planning,
diversity tracking, and department-level insights.
# Objective
Build a Power BI dashboard that allows HR stakeholders to explore employee distribution across departments, job titles,
locations and demographic categories, with ability to filter and drill down by key attributes.
# Data Source
The dataset was downloaded from kaggle. It consists of 22,0000 employee records across 13 departments and different jobtitles.
# Tools Used
Power Query for data cleaning, transformation and validation
DAX for calculated measures 
Power BI Desktop for dashboard design and visualization
# Data Cleaning
1. The data set was imported to power query for transformation.
2. Duplicate records removed.
3. Created calculated column for Age Group category
4. Standardized department and job title naming(Inconsistent casing/spelling)
# Dashboard Features
1. Total Employees; 22,000 employees across 13 departments
2. Gender Split;50.81% Male, 46.4% Female, 2.72% Non-Conforming
3. Employees by job title; Top roles include Research Associate, Business Analyst, HR, Account Executive
4. Age group filter; segment views by GenX, GenZ and Millenials
5. Count of department by job title and gender; Interactive breakdown for workforce planning
